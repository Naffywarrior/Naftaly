Apresento a vocês o meu primeiro projeto de site html, através do curso de Programação Web pelo Instituto Guararapes em parceria com o Senac.
A ideia do projeto surgiu com o acesso a mentorias online de váreas áreas mesclando com um tema de interesse pessoal: a comunicação que os gestos/expressões corporais passam inconscientemente; como ler e entendê-los.
Na página inicial, tive a intenção de declarar que o site é apenas um projeto não uma mentoria de fato. Na verdade, a mentoria do "Corpo em Cumunicação" é uma ideia de projeto para o curso 
para aprimoramento de conhecimento na área.
A página web consiste em: 
1 - Página inicial - onde contém os links das subpáginas, o vídeo de apresentação, comentários e o formulário;
2 - Subpágina SOBRE - onde contém informações do "Quem Somos" e sobre o objetivo da mentoria;
3 - Subpágina Mentoria Online - contém os vídeos-aulas e um pdf como suporte para as aulas;
4 - Subpágina LOJA - contém as redes sociais que seriam do meu "cliente" (mas como é um "faz de conta" coloquei minhas redes mesmo) e o link da "loja do próprio cliente" para adquirir produtos, 
que na lógica da ideia do projeto, são produtos relacionados ao tema que me foi solicitado na criação da página para vendas.
Para a elaboração do site foi usado as seguintes tecnologias básicas fundamentais do desenvolvimento web: html, css e java script.
